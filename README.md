# FuckKook

# 用法
将内容解压到你的kook根目录，不是app-xxxx里面，就是外面的根目录

每次启动要从“启动KOOK.exe”否则每次更新后需要手动安装，改一下自己的启动快捷方式习惯就行了

KookClean文件夹里面有个叫“kook-adblock.txt”

这个是广告匹配器，里面有教你如何匹配新广告，如果不会可以等更新或者提交Issues，也欢迎提交PR，欸嘿嘿

你可以点击软件左上角进入调试模式来定位广告或者其他元素，如果没有加载DLL，也可以用键盘Ctrl+Shift+Alt+0来唤起调试界面

不仅去除广告，并且阻止了KOOK进入主播模式，允许在 OBS 或 B站直播姬 运行的情况下使用Kook语音聊天
